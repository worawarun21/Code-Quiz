# Bag Borrow
## เเอพยืมคืนกระเป๋า
**วัตถุประสงค์ของระบบ**
'''
-เพื่ออำนวยความสะดวกในการยืมและคืนกระเป๋า
-เพื่อลดปัญหาการจดบันทึกข้อมูลด้วยกระดาษ
-เพื่อจัดเก็บประวัติการยืม-คืนให้ค้นหาได้ง่าย

**กลุ่มเป้าหมาย**
'''
-นักเรียน
-นักศึกษา
-บุคลากรภายในสถานศึกษา

**ฟังค์ชันหลักที่มี**
**ลงประกาศ/ค้นหากระเป๋า**
'''
–ผู้ให้ยืมโพสต์กระเป๋า (รูป, แบรนด์, ราคา) ผู้ยืมค้นหาและกรองตามที่ต้องการ

**จอง + ระบบมัดจำ**
'''
-เลือกวันที่ยืม จองคิว จ่ายมัดจำ/ค่าเช่าผ่านแอป

**รีวิวเเละติดตามสถานะยืม-คืน**
'''
– แจ้งเตือนวันครบกำหนดคืน และให้คะแนนรีวิวกันหลังทำธุรกรรมเสร็จ
